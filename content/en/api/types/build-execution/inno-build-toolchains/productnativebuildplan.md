```csharp
public System.Collections.Generic.IReadOnlyList<Inno.Build.Toolchains.NativeBuildRecipe> Inno.Build.Toolchains.ProductNativeBuildPlan.CreateRecipes(Inno.Build.Toolchains.NativeBuildContext context)
```

Resolves the complete selected source recipe closure before binding generation or native compilation.

**Parameter `context`:** The borrowed operation with a frozen target SDK; each step supplies its own component options.

**Returns:** Immutable recipes in declaration order, including each component's selected tools and parameters.
Actual generated bytes and dependency artifacts are added by the producer before publication.

**Throws `System.ArgumentNullException`:** The context is null.

**Throws `System.InvalidOperationException`:** Tools are unassigned or a declaration returns a foreign owner, component or target.

**Throws `System.NotSupportedException`:** A static component does not support the selected target.
