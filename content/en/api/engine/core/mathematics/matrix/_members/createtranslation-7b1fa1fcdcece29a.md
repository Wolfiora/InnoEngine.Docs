Creates a translation matrix.

**Parameter `x`:** Translation on X axis.

**Parameter `y`:** Translation on Y axis.

**Parameter `z`:** Translation on Z axis.

**Returns:** A translation matrix whose translation resides in (m14, m24, m34).
