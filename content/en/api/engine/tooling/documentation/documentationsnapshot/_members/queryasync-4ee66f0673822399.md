Searches, reads, resolves symbols or resources, or reports binding status without mutating the index.

## Remarks

Equally ranked multiword heading matches prefer task guides. Exact symbol and identifier searches retain their reference priority; excerpts still require explicit contract reads.

**Parameter `request`:** A structured operation against this snapshot. Search excerpts are never returned as complete contracts.

**Parameter `cancellationToken`:** Cancels query work or page lease acquisition; the session remains reusable after cancellation.

**Returns:** Explicit content, empty, ambiguity, missing, continuation or mismatch results with snapshot provenance.

**Exception `T:System.ArgumentException`:** The operation, offset, limit or required selector is invalid.

**Exception `T:System.IO.IOException`:** A selected immutable payload is missing, corrupt or escapes the cache boundary.

**Exception `T:System.OperationCanceledException`:** The operation was canceled before its result was returned.

**Exception `T:System.ObjectDisposedException`:** The session has released its reading protection.
