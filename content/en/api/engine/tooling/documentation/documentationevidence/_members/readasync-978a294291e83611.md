Reads one bounded certificate whose digest was obtained independently from a trusted producer. It performs no network access, source scan, compilation or cache mutation.

**Parameter `path`:** Explicit local certificate file; symbolic links are rejected.

**Parameter `trustedIdentity`:** SHA-256 obtained from an authenticated workflow artifact or locally reconciled producer. Computing this value from an arbitrary downloaded file does not establish trust.

**Parameter `cancellationToken`:** Cancels reading before an immutable certificate is returned.

**Returns:** A caller-owned immutable value, reusable across matching snapshot sessions.

**Exception `T:System.IO.IOException`:** The file is missing, oversized, linked, corrupt or structurally invalid.

**Exception `T:System.OperationCanceledException`:** The read was canceled.
