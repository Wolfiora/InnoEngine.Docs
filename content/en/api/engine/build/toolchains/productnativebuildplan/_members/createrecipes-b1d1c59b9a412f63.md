Resolves the complete selected source recipe closure before binding generation or native compilation.

**Parameter `context`:** The borrowed operation with a frozen target SDK; each step supplies its own component options.

**Returns:** Immutable recipes in declaration order, including each component's selected tools and parameters. Actual generated bytes and dependency artifacts are added by the producer before publication.

**Exception `T:System.ArgumentNullException`:** The context is null.

**Exception `T:System.InvalidOperationException`:** Tools are unassigned or a declaration returns a foreign owner, component or target.

**Exception `T:System.NotSupportedException`:** A static component does not support the selected target.
