# Assets

Find types in this project category. Each type links to its exact declarations and member contracts.

## Types

| Type | Purpose |
| --- | --- |
| [IUiDocumentFrontend](iuidocumentfrontend/index.md) | Validates one UI document language without creating runtime UI objects. |
| [UiDocumentAnalysis](uidocumentanalysis/index.md) | Returns validated text without retaining parser or implementation objects. |
| [UiDocumentDiagnostic](uidocumentdiagnostic/index.md) | Reports a language-neutral source problem. |
| [UiDocumentFontDeclaration](uidocumentfontdeclaration/index.md) | One font asset declared by a UI document language frontend. |
| [UiDocumentFrontendCatalog](uidocumentfrontendcatalog/index.md) | Owns one immutable UI language registration snapshot. |
| [UiDocumentFrontendRegistry](uidocumentfrontendregistry/index.md) | Discovers UI language frontends through the shared type-generation transaction. |
| [UiDocumentImporter](uidocumentimporter/index.md) | Imports implementation-neutral UTF-8 UI source using explicit sidecar settings. |
| [UiDocumentImportPipeline](uidocumentimportpipeline/index.md) | Coordinates source analysis, font dependencies, and runtime UI asset emission. |
| [UiDocumentImportSettings](uidocumentimportsettings/index.md) | Explicitly selects language and runtime implementation for neutral UI source. |
| [UiDocumentSourceFile](uidocumentsourcefile/index.md) | Contains immutable source text supplied to a UI language frontend. |
