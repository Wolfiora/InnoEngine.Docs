# Authoring

Find types in this declared script scope. Each type links to its exact declarations and member contracts.

## H

| Type | Purpose |
| --- | --- |
| [HeaderAttribute](headerattribute/index.md) | Starts a visually separated Inspector section before the annotated property. |
| [HelpBoxAttribute](helpboxattribute/index.md) | Draws a wrapped explanatory message before the annotated Inspector property. |
| [HideIfAttribute](hideifattribute/index.md) | Hides the annotated Inspector property when a sibling member satisfies a condition. |

## I

| Type | Purpose |
| --- | --- |
| [InspectorCondition](inspectorcondition/index.md) | Defines the comparison used by conditional Inspector presentation. |
| [InspectorMessageType](inspectormessagetype/index.md) | Selects the visual severity of an Inspector help message. |
| [InspectorNameAttribute](inspectornameattribute/index.md) | Replaces the generated Inspector label for one property. |
| [InspectorPresentationAttribute](inspectorpresentationattribute/index.md) | Provides editor-only presentation metadata for one serialized field or property. |
| [InspectorReadOnlyAttribute](inspectorreadonlyattribute/index.md) | Makes an otherwise writable serialized property read-only in the Inspector. |

## R

| Type | Purpose |
| --- | --- |
| [RangeAttribute](rangeattribute/index.md) | Constrains a numeric Inspector control to an inclusive range. |

## S

| Type | Purpose |
| --- | --- |
| [ShowIfAttribute](showifattribute/index.md) | Shows the annotated Inspector property only when a sibling member satisfies a condition. |
| [SpaceAttribute](spaceattribute/index.md) | Inserts vertical spacing before the annotated Inspector property. |

## T

| Type | Purpose |
| --- | --- |
| [TextAttribute](textattribute/index.md) | Draws persistent wrapped explanatory text before the annotated Inspector property. |
| [TooltipAttribute](tooltipattribute/index.md) | Provides hover help for one Inspector property label. |
