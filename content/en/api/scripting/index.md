# Scripting API

Browse the actual projected script API by its declared scope. Runtime contracts are also available to Editor scripts; Authoring annotations are compilation-time contracts.

## Categories

| Category | Purpose |
| --- | --- |
| [Authoring](authoring/index.md) | Stateless Inspector presentation metadata with an explicit authoring-only script surface. |
| [Editor](editor/index.md) | Browse Editor contracts from Inno.Assets.Pipeline, Inno.Core.Serialization, Inno.Editor.Assets, Inno.Editor.Assets.ImGui and related projects. |
| [Runtime](runtime/index.md) | Browse Runtime contracts from Inno.Animation, Inno.Assets, Inno.Audio, Inno.Core.Diagnostics and related projects. |
