## Learn the engine's vocabulary

InnoEngine separates product composition from reusable mechanisms. Hosts own sessions and resources; backends implement neutral capabilities; persistent identities survive reconstruction while runtime identities belong to a live registration.

The [glossary](about/glossary.md) introduces these terms. [Ownership](architecture/ownership.md) explains the lifetime rules that connect the Manual and API reference.
