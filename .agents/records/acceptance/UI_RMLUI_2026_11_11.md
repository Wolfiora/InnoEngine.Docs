## Content and source corrections

New task guides cover displaying an imported document, authoring RML with controlled RCSS/font dependencies, and consuming retained rendering frames. An architecture explanation separates frontend, asset, session, native and GPU ownership. Eight authoritative project entries connect those tasks to 72 generated type pages and eight type indexes. A backend guide states actual limitations rather than inheriting upstream capabilities.

Source review corrected old claims about the neutral import extension, Input/Text frame dependencies, UiInputSnapshot export, obsolete texture type names, stylesheet support and font registration sharing. It also preserves the distinct failure behavior of frame acknowledgment, event clearing and disposal. The current adapter clears events in finally and does not retry native destruction after marking itself disposed; neither is described as guaranteed recovery.

Engine XML changes clarify plain-text escaping and setter success without changing executable text or public signatures. The RML source example requires an actual user-provided font; it is not a claim of native visual execution. Native ABI reference uses explicit shared ownership associations and preserves generated declarations without editing the bindings.
