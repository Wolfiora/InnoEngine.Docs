## Behavior

An explicitly dispatched Documentation run accepts a successful engine run ID. Its restricted GitHub App token reads only the engine repository's Actions and content. Selection requires the expected workflow, repository, branch, exact source revision, successful aggregate and retained successful-attempt source certificate. Archive digest verification and bounded extraction precede acceptance of the certificate file identity. PR jobs never receive that installation token.

The canonical adapter passes the immutable certificate to the query library. The library checks the complete source tree, project inventory and API reference coverage without scanning source, fetching data or compiling during reads. Source evidence remains separate from content snapshots. The site completion and publication manifests require the exact evidence identity; a Verified label alone cannot qualify a site.

This implements the preparation boundary. It is not proof that the organization installation exists or that complete Windows/macOS/Browser source comparison has passed. Without those prerequisites, the complete gate remains blocked and no verified site artifact is published.
